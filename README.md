# Aaran

Minimal static web project for the registration form.

## Local development

1. Open the project folder in VS Code.
2. Install the recommended **Live Server** extension when prompted.
3. Open [home.html](./home.html).
4. Click **Go Live** in the VS Code status bar.
5. Use the **Launch Edge** debug configuration to open the page at `http://localhost:8080`.

The Live Server extension reloads the page when files change. No Node.js or Python installation is required.
